Requires `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` environment variables (consumed by `supabaseClient.js`). The email subsystem expects a matching Next.js API route at `app/api/send-email/route.js` (or equivalent) because `emailNotificationService.js` POSTs to `/api/send-email`. Admin password and recipient addresses are read from the `jmis_settings` Supabase table at runtime.
