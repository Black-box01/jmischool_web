Two Next.js applications live side-by-side under the same repo: `app/` serves the marketing website while `src/app/` hosts the exam quiz portal. They share dependencies declared in the root `package.json` (`@supabase/supabase-js`, Bootstrap, React 19, Tailwind v4) and are configured through a single `next.config.mjs` that exposes shared environment variables (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `NEXT_PUBLIC_STUDENT_PORTAL_URL`, `NEXT_PUBLIC_ADMIN_URL`) plus remote image allowlisting for the Supabase storage bucket. Both apps connect to the same Supabase project at `btnatydmfunhwgoeguus.supabase.co`, with the marketing site reading content from a `jmis_settings` row and the exam portal persisting session state and results there; cross-app navigation is done via the `NEXT_PUBLIC_STUDENT_PORTAL_URL` / `NEXT_PUBLIC_ADMIN_URL` env vars rather than shared code.
